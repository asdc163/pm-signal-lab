# PM Interview to Insight

Turn de-identified interview notes, usability sessions, or workflow
observations into an evidence-bounded insight map and one next learning action.

The skill is deliberately narrow:

- source IDs and safe context stay attached to each observation;
- jobs, friction, outcomes, requests, and interpretations stay separate;
- one session remains a signal rather than a market conclusion;
- repeated qualitative signals keep their context and do not become a rate;
- contradictions and missing evidence remain visible;
- the output ends with one reversible question or smallest validation.

Start with the [fictional first run](./examples/first-run.md), then read the
[worked support-interview insight map](./references/support-interview-insight-map.md).
Copy `SKILL.md` into an Agent Skills-compatible client. No provider, tool,
network access, login, or external write is required.
