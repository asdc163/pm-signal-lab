# PM Proof to Share

`pm-proof-to-share` turns a verified product or skill release into a small,
evidence-backed English share pack. It gives a maintainer one audience, one
channel, one useful first action, a proof ledger, visible boundaries, and a
concrete feedback ask.

## Use it when

- a release is public but the first-use story is hard to explain;
- a README, release note, Discussion, or community draft risks becoming vague
  promotion;
- a maintainer needs to keep local, CI, hosted, participant, and adoption proof
  separate;
- a public message should teach the reader something useful before asking for a
  reaction.

## Run it

1. Copy [`examples/first-run.md`](./examples/first-run.md) into a compatible
   Agent Skills client.
2. Replace the fictional release with current, sanitized proof and keep source
   links, version, confidence, and limitations visible.
3. Compare the result with the [worked share pack](./references/release-proof-share-pack.md).
4. Have a human review the channel, links, claims, privacy boundary, and
   `Review ask` before publishing anywhere.

## Boundary

This is a tool-free, model-agnostic planning skill. It does not post, reply,
send DMs, request stars, create issues, collect telemetry, or prove traffic,
adoption, quality, safety, or business impact. The included materials are
fictional fixtures and are not user testimonials.

## Verifier

The repository verifier checks frontmatter, required sections, fictional
first-run and worked-example boundaries, line budget, and placeholder scan.
