# Security policy

PM Signal Lab v0 is a local, fixture-driven preview. It does not accept API keys, authenticate users, upload evidence, or call external providers.

Please do not post secrets, private customer data, access tokens, wallet keys, or confidential evidence in public issues. If you find a security problem in the repository or a future public deployment, use GitHub's private vulnerability reporting when it is enabled for this repository; otherwise contact the maintainer privately before disclosure.

Security reports are handled as a release gate. A reproducible privacy, secret, permission, or external-side-effect issue blocks the affected release until there is a fix, mitigation, and fresh verification.
