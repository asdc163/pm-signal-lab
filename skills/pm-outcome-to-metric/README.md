# PM Outcome to Metric

Turn a product outcome or AI product goal into an evidence-bounded metric
contract before an experiment, rollout, or evaluation.

The skill keeps these boundaries visible:

- user outcome is not the same as a click, generated output, or internal
  activity;
- a primary metric is not a guardrail or diagnostic;
- a proposed target is not a baseline or achieved result;
- an event name is not implemented telemetry;
- a model score is not automatically a user outcome;
- missing denominators, privacy gaps, and version boundaries stay in the handoff.

Start with the [fictional first run](./examples/first-run.md), then read the
[worked support-review metric contract](./references/support-review-metric-contract.md).
Copy `SKILL.md` into an Agent Skills-compatible client. No provider, tool,
network access, login, or external write is required.
