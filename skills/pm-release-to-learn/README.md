# PM Release to Learn

Turn a verified release into a bounded rollout-and-learning plan.

The skill keeps these states separate:

- release proof is not rollout exposure;
- exposure is not adoption;
- traffic is not value;
- a pilot is not production;
- a written rollback action is not a tested rollback;
- owner feedback is not external usage evidence;
- a star is not a learning signal.

Start with the [fictional first run](./examples/first-run.md), then read the
[worked support-review release learning plan](./references/support-review-release-learning.md).
Copy `SKILL.md` into an Agent Skills-compatible client. No provider, tool,
network access, login, or external write is required.
